Integritet

Integritetspolicy

Kortfattat om vilken data spelet och webbplatsen hanterar.

Omfattning: Policyn gäller den nuvarande webbversionen av spelet och webbplatsen askfalt.se. Den ska stämmas av mot den färdiga iOS-versionen före App Store-lanseringen. Senast uppdaterad: 11 oktober 2026.

Spelet

Webbversionen kräver inget konto. Sparade spel och inställningar lagras lokalt på din enhet, i webbläsarens lagring. Vi tar inte emot den informationen.

Spelet är byggt för att kunna användas offline efter installation som PWA. Webbversionen publiceras på en separat domän via en webbhotellstjänst som, likt alla webbservrar, behandlar tekniska uppgifter som IP-adress när filerna levereras. Webbspelet kan hämta typsnitt från Google Fonts när nätverk finns.

Webbplatsen

askfalt.se publiceras via GitHub Pages. Webbplatsen använder inga cookies, inga analysverktyg, ingen reklamspårning och inga kontaktformulär, och hämtar inga resurser från tredje part. GitHub kan behandla tekniska uppgifter när sidorna levereras, enligt GitHubs egna villkor.

Om du kontaktar oss

Om du skapar ett ärende på GitHub är innehållet offentligt och omfattas av GitHubs villkor. Om du mejlar oss använder vi uppgifterna enbart för att besvara ditt ärende.

Framtida funktioner

En iOS-version är under utveckling. Konton och multiplayer är planerade till en senare version och ingår inte i den nuvarande webbversionen. Policyn uppdateras innan sådana funktioner lanseras.
