Support

Askfält is in active development. Here you will find answers to common questions and how to report bugs.

Report a bug

Open an issue on GitHub. Describe what happened, how to reproduce it, and which device, browser and game version you use.

Open GitHub Issues

Security issues

Found a vulnerability? Report it privately by email, not in a public issue.

security@askfalt.se

Before you open an issue

  • Search the existing issues in case the bug is already reported.
  • Include a screenshot and the steps that lead to the bug if you can.
  • GitHub issues are public. Do not include personal data, save files, passwords or keys.

Responsible disclosure

Send security-related reports to security@askfalt.se. Describe the problem, how to reproduce it and which version is affected. Please do not publish details until the issue has been fixed. The contact details are also listed in security.txt.

Frequently asked questions

Where are my saves stored?

The web version stores saves and settings locally in the browser you play in. Clearing the browser’s site data may delete your saves. Storage in the upcoming iOS app is being tested separately.

Can I play offline?

Yes. The PWA version is built to work offline once its resources have been downloaded.

How do I install the game as an app?

Open the web version and choose “Add to Home Screen” (Safari) or “Install app” (Chrome and Edge).

Is there multiplayer?

Not yet. Multiplayer is planned for a later version.

When is the iPhone app coming?

The target is November 1, 2026, subject to testing and Apple’s review. An App Store link will only appear here once the app is published.
