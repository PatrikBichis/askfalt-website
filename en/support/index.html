Support

Askfält is actively developed. It is currently available as a web game and PWA. The iPhone edition is being prepared for TestFlight.

Report an issue

Open a GitHub support issue with device model, browser, game version and reproduction steps. Do not post personal data or save files in public issues.

Saved games

Web saves reside in your browser. Clearing site data may remove them. Native iOS storage will be verified separately.

FAQ

Can I play offline?

The installed PWA is designed for offline use once its assets have been cached.

Is there multiplayer?

Not yet. Multiplayer is planned after v3.0.

When is the iPhone edition coming?

The target is November 1, 2026, subject to testing and Apple's review.
