Privacy

Privacy policy

A short summary of what data the game and the website handle.

Scope: This policy covers the current web version of the game and the website askfalt.se. It will be reviewed against the final iOS build before the App Store launch. Last updated: October 11, 2026.

The game

The web version does not require an account. Saves and settings are stored locally on your device, in the browser’s storage. We do not receive that information.

The game is built to work offline once installed as a PWA. The web version is published on a separate domain through a hosting service which, like any web server, processes technical data such as IP addresses when delivering files. The web game may load fonts from Google Fonts when a network is available.

The website

askfalt.se is published via GitHub Pages. The website uses no cookies, no analytics, no ad tracking and no contact forms, and loads no third-party resources. GitHub may process technical data when delivering the pages, under GitHub’s own terms.

If you contact us

If you open an issue on GitHub, its content is public and covered by GitHub’s terms. If you email us, we only use the information to respond to your request.

Future features

An iOS version is in development. Accounts and multiplayer are planned for a later version and are not part of the current web version. This policy will be updated before such features launch.

Contact

Privacy questions can be sent to security@askfalt.se.
