Privacy policy

Scope: This policy describes the current web edition and website. It must be rechecked against the final Capacitor app before App Store release. Last reviewed: October 11, 2026.

The game

The current web edition requires no player account. Saved games and preferences are stored locally in your browser. The PWA is designed to work offline once installed.

This website

This information site is hosted on GitHub Pages. We have not integrated our own analytics, advertising trackers, or contact forms. GitHub may process technical connection data according to its policies.

Third parties

The web game may request fonts from Google Fonts while online. The web game opens on a separate domain.

Planned functionality

An iOS edition is in development. Supabase-powered accounts and multiplayer are planned for a later release, not part of the current web edition. This policy will be revised before those features launch.

Contact

For privacy questions, use the public issue tracker without posting personal or confidential information. A dedicated contact address must be confirmed before public App Store release.
