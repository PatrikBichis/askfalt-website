# Bildlista – kompletterande material för v1.x

Befintligt material räcker för v1.0. Följande skulle stärka sidan. Leverera som PNG i originalupplösning (heltalsskalning bevarar pixelgrafiken), helst utan HUD.

| # | Motiv | Används i | Format |

| 1 | Hero i skymning: koloni med varma fönster, ingen logotyp/HUD | Hero (`#top`) | 16:9, minst 1920×1080 |
| 2 | Återtagen robot som bär last eller vaktar | Återta maskinerna (`#reclaim`) | 16:9 eller 4:3 |
| 3 | Nätets drönare/markrobot i närbild | Försvar (`#defend`) | 16:9 |
| 4 | Vakttorn och utpost med siktradie | Försvar | 16:9 |

| 7 | Nod i Nätets infrastruktur | Milstolpe / tidslinje År 11 | 16:9 |
| 8 | Större bosättning sent i spelet | Kolonins tillväxt, tredje steget | 4:3 |
| 9 | Gameplayvideo 30–60 s, utan ljudkrav | Trailer (`#video`) | 1920×1080 MP4 (H.264) + WebM, poster-PNG |
